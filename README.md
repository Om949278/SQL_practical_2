This SQL code creates a student marksheet system where each student’s academic record is stored in a structured table. The table student_marksheet uses enrollment_no as the primary key to uniquely identify every student. It contains columns for the student’s name, branch, semester, and marks in five subjects—Maths, Physics, Chemistry, Programming, and Electronics. Alongside these, it also stores the total marks and the percentage, which summarize the student’s overall performance.

After defining the table, the script inserts sample data for ten students from different branches like CSE, ECE, and IT. Each record includes subject-wise marks, the calculated total, and percentage. For example, Neha (ENR005) from ECE scored the highest with 466 marks and a percentage of 93.20, while Rohit (ENR004) from CSE scored 391 marks with 78.20%. Finally, the query SELECT * FROM student_marksheet; retrieves all the rows, displaying the complete marksheet with student details and their performance.

In short, this code models a digital marksheet database that makes it easy to store, manage, and query student results, allowing quick comparisons of performance across branches and semesters.
